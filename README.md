# Mystic Browser — Android starter

This is a small, editable Android Studio starter for **Mystic Browser** with a red M identity and a dark glass-inspired UI.

## Important scope note
This starter is **not a rebranded Brave build** and does not include Brave's Shields, sync, rewards, Leo, or other Brave-specific features. The APKs supplied were compiled APK splits, not the full editable source tree. To preserve Brave's complete functionality, start from the official open-source repositories and comply with their licenses and trademark requirements:
- https://github.com/brave/brave-browser
- https://github.com/brave/brave-core
- Android build guide: https://github.com/brave/brave-browser/wiki/Android-Development-Environment

Do not publish this starter as an official Brave product. Use your own app identity and review all upstream license notices before distributing a fork.

## Open and build
1. Install Android Studio with a current Android SDK.
2. Open this folder in Android Studio.
3. Let Gradle sync.
4. Run on an Android device or emulator.

This starter uses Android WebView for basic browsing. It is a starting point, not a production-hardened browser. Before public release, add safe browsing/security review, download handling, permissions review, privacy policy, testing, and proper signing.
